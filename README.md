# Objetos Personalizados — D&D 5e

Módulo de Foundry VTT con un compendio de objetos mágicos y equipamiento homebrew para campañas de D&D 5e.

## Instalación

En Foundry VTT → **Configuration → Add-on Modules → Install Module → Manifest URL**:

```
https://github.com/JaraEsequiel/custom-items-dnd5e/releases/latest/download/module.json
```

## Contenido

- **Magic Items**
  - Cigarro del Dragón
